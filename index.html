Historique

Les dernières annonces diffusées avec Difup.

Prototype de test. Quand c'est possible (PDF déposé + autorisation Claude accordée dans ce navigateur), les champs de l'annonce complète sont réellement extraits par lecture automatique du PDF ; le post rapide (photo + message) ne passe pas par cette lecture, il suit directement à l'écran de vérification. Sinon, des données d'exemple illustrent le parcours (voir le cahier des charges, module de saisie). Les pastilles Facebook/Instagram/Site en haut indiquent l'état de connexion du compte (pour l'instant toujours « connecté » à titre d'exemple — la vraie vérification de connexion arrivera avec les API Meta et le site du client). La fréquence de republication est enregistrée avec chaque annonce, mais la republication automatique elle-même n'a pas encore de moteur réel derrière (ça viendra avec le backend de planification, hors périmètre de ce prototype).
